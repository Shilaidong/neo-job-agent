# Terra-Edu Neo 界面重构计划 —— 黑白·纸感·精英

> 状态：**计划稿，未渲染**。方向未经用户逐条确认，按 oil-ui-pro 规矩这只是方向卡加迁移方案，确认后选定的条目才誊进 `DESIGN.md`。
> 范围：整个产品的「优化 UI · 升级档」。意图：推翻现有视觉语言，**不**改流程和页面结构。

---

## 0. 定档与一句话结论

这是一次**升级档**重设计：重新决定字体关系、色彩比例、密度、组件的样子，**保留**页面结构（左网页 / 右对话）、全局导航（首页→新建/设置→任务）、既有交互流程。理由：两栏结构是产品本体，改结构属于重塑档，会牵连浏览器层的所有既成坑，不值当。

**北极星**：用起来像一份高级机构的印刷文件——顾问每天要在工作区里看几百次，界面应该退到纸的那一边，让申请网页和对话内容站到前面来。

## 1. 模糊词翻译（用户语言 → 可观察决定）

| 用户说了 | 翻成界面决定 |
| --- | --- |
| 简单的黑白 | 全页只有一种墨色 + 纸灰阶。控件、边框、文字零彩色；彩色被赶去只做三颗 6px 状态点（低饱和），且状态另有文字/形状冗余 |
| 高端·奢侈品 | 不靠装饰靠公差：1px 发丝线、字距纪律、色温统一（中性偏暖的“纸”灰阶，不用科技蓝灰）、阴影全页只留一处 |
| 精英风味 | 小字宽字距的拉丁大写标签（kicker）、等宽数字排日期和金额、主动作用黑底白字反转块、没有一句废话文案 |
| 方便使用 | 正文 13–14px 起步，对比度全部 ≥ 4.5:1；行高 1.6；键盘可达；不靠悬停才出现的入口 |
| 不占资源 | 零网页字体、零依赖、零运行时动画库。系统字体栈 + 纯 CSS 过渡，每帧只动 transform/opacity |
| 工作为主、清晰 | 密度按每天用几小时的顾问定：任务行 36px，一屏 ≥ 20 个对象；卡片套卡片的层级拆掉，用对齐和留白分组 |

## 2. 品类与标杆

品类：macOS 桌面**专业工具**（留学顾问工作台），核心对象是“一份申请”，主动词是“推进流程”。

拆过的标杆（**未看图，凭记忆；字体、色彩两栏标待验证**，动手做样板页前先截图复核）：

- **Linear / Things 3**：专业工具的结构底线——行高、键盘优先、状态克制。沿用：密度和层级手法。换掉：它们的蓝紫强调色和柔影。
- **Vercel Geist**：黑白灰 + hairline 的完成度底线。**危险点**：cool-gray + Inter + 圆角 8 是这个品类人人抄的“默认答案”，直接撞脸。对策见差异检验。
- **奢侈品品牌的静默语汇**（The Row / Celine 的排印）：不是搬广告，借三件可执行的事——**中性偏暖的纸张色温**、**极小大写标签的宽字距**、**几乎不出现的东西才显眼**。

## 3. 调性五刻度

安静（顾问天天看，网页才是主角）· 精致（公差严格，无噪点无颗粒）· 中密（专业工具密度）· 轻（字重和色块面积都克制，重只留给黑底反转按钮）· 庄重（圆角小，无插画，动效极短）。

## 4. 设计系统（新语义角色，全部替换现有变量）

### 4.1 色彩

生成引擎是「材质×环境」：**哑光纸张**——产品做的是申请文书，UI 的物性就该是纸：不反光、不发蓝、不发黄，只比中性冷一点暖一点都不是，是“刚出打印机”的暖纸。

```
--paper    #FCFCFB  应用底色（唯一的“白”，带一丝暖）
--surface  #FFFFFF  卡片 / 对话面板 / 输入
--raise    #F6F6F4  悬停行、填充式次级按钮
--ink      #121110  正文与一级文字（不是 #000，纸上的墨不是纯黑）
--ink-2    #6E6C68  次要文字（4.7:1 on paper）
--ink-3    #A8A6A1  占位、三级信息
--line     #E6E4E0  发丝线：一切分隔
--line-ink #121110  强调线：选中、focus、提问卡边框
--on-ink   #FFFFFF  黑块上的白字
状态色，只准出现在 6px 圆点和极小文字上，降饱和：
--st-idle  #2E6B4F   --st-run #A87B12   --st-error #8F3A23
```

自检：去掉全部圆点色后页面依然说得清状态——靠文字「工作中 / 已完成 / 出错」+ 形状（圆点 vs 方点）。

### 4.2 字体

系统栈，零下载：`-apple-system, "SF Pro Text", "PingFang SC"`；数字一律 `ui-monospace, "SF Mono"` + `font-variant-numeric: tabular-nums`。

| 角色 | 尺寸 / 字重 / 字距 |
| --- | --- |
| 页面题（首页 h1） | 22 / 600 / -0.01em |
| 区块题 | 15 / 600 / -0.005em |
| 正文 | 14 / 1.6（对话正文 15） |
| 辅助 | 13 / --ink-2 |
| kicker 标签 | 10 / 600 / **0.1em** / 大写 / --ink-3 |
| 数据（日期·额度·计数） | 13 / mono |

中文只走 PingFang 真实字重，禁 faux bold；长句断行在真实内容上看过再定。

### 4.3 形

- 圆角：控件 **6**、卡片 **10**、圆点 50%。**tag 从胶囊改 4px 矩形**——这是“编辑感”的关键一刀。
- 边框：1px 发丝线；2px 只留给 focus ring 和当前选中项。
- 阴影：**全页一处**，☰ 菜单 `0 12px 40px rgba(18,17,16,.10)` 配 1px 边框。其余零阴影。
- focus：`outline: 1.5px solid var(--ink); outline-offset: 2px`，取代浏览器默认蓝晕。

### 4.4 控件语法

一套规则贯穿按钮、输入、下拉、标签：**静止= 发丝线框 + 白底；悬停= 底换 --raise；按下= 位移 0.5px + 线变深；选中/主动作= 黑底白字反转块**。输入框静止时底用 --paper，focus 变白 + 1.5px 墨线。图标沿用现在的文字符系统（‹ › ↻ ☰），需要图形时用 Phosphor Thin 16px 内联 SVG——**不装库、不加依赖**，用几个拷几个。

### 4.5 动效（三处基本动效，全 CSS）

1. 悬停/聚焦：**120ms ease-out**，只动颜色。
2. 消息入场：opacity 0→1 + translateY 2px，**160ms**。
3. 打字进行中：流式文本末尾一枚 **1s 阶跃闪烁的实心块光标 ▌**；工具行的“工作中”用 1px 墨线从左到右扫过。
`prefers-reduced-motion` 保留现有规则。总成本：每帧 transform/opacity，GPU 友好，零 JS。

### 4.6 记忆点

「AI 正在干活」这件事本身就是内容：黑方块光标在对话末尾呼吸，像一份还在排印的文件。**白底黑字成立，不需要任何材质和发光**——这就是给奢侈品语言找的产品真实动作，不是装饰。

## 5. 差异检验（对照撞脸风险）

- 线框/结构不重做，属升级档，这是档位决定的。
- **色彩身份**：Vercel 是冷灰 #F7F7F8/#000 + 8px 圆角；这里是**暖纸灰阶 + 6px 圆角 + 4px 矩形 tag + 状态色退到 6px 点**。眯眼看块面，与 Geist 家族分得开。
- **字体性格**：Geist 靠 mono logo 和 cool 蓝灰说话；这里靠中文排印的宽字距 kicker 和方块光标，品类里没人这么做。
- 没有黑底、没有渐变、没有弥散光——这三样是本方向**主动放弃**的东西。

## 6. 逐屏迁移方案

改的是 `styles.css`（唯一样式文件）加各视图里少数 class，**渲染层逻辑与 IPC 一行不动**。顺序按“一个代表页做完整再铺开”：

1. **提交 A — 变量与全局**：`:root` 换成新角色，`body/按钮/输入/卡片/滚动条` 全部重映射到变量。所有页面自动换血但结构不变。
2. **提交 B — Workbench（代表页）**：toolbar、☰ 头、气泡/工具行/提问卡/风险卡/交接条/输入区；侧栏密度收到 36px 行高。**做完必须 `NEO_SHOT_VIEW=task` 真截图**，专门复查两件旧坑：☰ 在 252px 面板里不被原生网页盖住（flex-wrap 那条注释不许碰）、长校名截断仍一行。
3. **提交 C — Home**：任务列表成排账本：kicker「学生 · 申请」+ 学校 600 + mono 日期右对齐 + 状态点带文字。额度块改 mono 反转小框。
4. **提交 D — NewTask**：字段栅格保留，区块头加 kicker，选校清单行去掉卡片套卡片，直接发丝线排。
5. **提交 E — Settings**：612 行里最大的视图，只做视觉映射不改布局；模型行密度对齐 Home。
6. **提交 F — Login / 启动·失败·空态**：启动页是边角，一处巧思放这——「正在启动…」用发丝线 + 方块光标，呼应主记忆点。

每个提交后跑 `bun run typecheck && bun test src`，合入前全量 `bun run smoke`；每屏一张改前/改后 `NEO_SHOT` 截图存档进 `docs/screens/`。
**评审**：升级档不打分——样板页（B）做完派一轮独立评审「给已有界面评审」，标准是本计划 §4；之后 C–F 只复看改动处。

## 7. 不动清单与硬边界

- 两栏结构、☰ 菜单内容、拖宽把手（340–760px clamp）、`-webkit-app-region` 拖拽带、原生 WebContentsView 的 z-order 现实：所有浮层只准出现在右栏 DOM 内。
- `side-head` 保持单行 ellipsis（2026-10-07 那处注释的原因）。
- 不引入新依赖、不引入网页字体、不引入组件库；不顺手重构 TS 逻辑。
- 文案不改写，只换排印角色——工具名翻译在 `labels.ts`，那是内容层，另议。
- Terra 陶土色 `--terra` 整体退役：用户已拍板黑白，它不是需要保的品牌资产，是历史偶然值；品牌只留「Terra-Edu 申请助理」字标一处。

## 8. 验收线

- 每屏截图人眼过一遍：无发丝线错位、无一处彩色泄漏、无 2px 以上边框残留、tag 全部方形。
- 可读性：100% 尺寸下最长中文标题、200% 放大看 1px 线不糊。
- 对比度：`--ink`/`--ink-2` 对 paper ≥ 4.5:1（已验 12.6:1 / 4.7:1）。
- 资源：CSS 净增 ≤ 4KB，JS 增量为 0，首帧不新增布局成本。

## 9. 需要用户点头的四处

1. 状态色按 §4.1 退到“只进圆点”——还是全灰阶、状态纯靠文字？
2. 圆角 6/10 的柔和派，还是 0 的严整派？
3. 打字方块光标当记忆点——受得了它一直在闪，还是只在流式输出时闪？
4. 陶土色退役的确认（§7 已按退役写）。
